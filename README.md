## 📖 О проекте

**«Игровой центр»** — это сборник браузерных мини-игр, созданный для демонстрации продвинутой работы с чистым JavaScript. Здесь реализованы полноценные игровые механики, управление логикой и динамическое обновление интерфейса без использования сторонних библиотек.

В текущей версии представлены игры:
-  «Угадай число», «Простая арифметика», «Переверни текст», «Камень, ножницы, бумага», «Простая викторина», «Генератор случайных цветов»,.

## 🛠️ Используемые технологии

- **HTML5** — создание игровых полей и элементов управления.
- **CSS3** — адаптивный дизайн, анимации состояний (победа/поражение), стилизация под единый геймерский стиль.
- **JavaScript (Vanilla JS)** — вся игровая логика: генерация случайных чисел, таймеры (`setInterval`), манипуляции с DOM, обработка кликов и клавиатурных событий.
